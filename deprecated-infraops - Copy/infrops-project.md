1. Issue Understanding - a model that sees and understands the issue.

Objective 1:
multimodel Engine for Maintenance report analysis
based on text, images, video,
datasets:
1. 311 service request dataset for text
2. RDD2022 - road damage detection dataset
3. SDNET2018: A concrete crack image dataset for machine learning applications
4. TACO Dataset (Trash Annotations in Context), for litter and garbage detection
 
Goal: Develop an AI module that automatically understands maintenance complaints from text and images, identifies the type of issue, and extracts key information such as category, severity, and location. This converts unstructured user reports into structured data that can be used for intelligent decision-making in later stages.
